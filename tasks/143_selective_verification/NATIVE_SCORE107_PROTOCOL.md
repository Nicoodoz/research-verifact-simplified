# 143辅助历史180面板：固定原生分支分数送审粗筛

先冻结本规则，再读取GT计算结果。只使用113已有的107分支概率与同ID原greedy标签，不运行模型、训练、API或人工复核；不与1817面板合并。

输入：`.local_models/113_label_path/evidence/results/scores/*.json`，`.local_models/113_label_path/baseline107.jsonl`，`.local_models/113_label_path/keys.jsonl`及原113配置。每个ID须在原pilot内，原greedy有效，权重身份为107的`096f30c4…`，分数与greedy的prompt token SHA一致，GT/患者键一致。任一身份或字段不符则停止，不补分数。

分数只用真实`first_branch.S`及`first_branch.Not`，须有限、均在[0,1]、合计>0且不超过1（允许1e-6浮点误差）。定义`confidence_S = p(S)/(p(S)+p(Not))`。这是同一JSON前缀位置的两分支相对分数，不是校准概率或完整三类后验；不使用restricted_q重新给标签。

自然120、压力60分别计算；另列全180且只称富集诊断。对每个面板原107判S的M例，按`(confidence_S升序, ID字典序)`排序；固定送审比例为0%、5%、10%、20%、30%，送审数`k=floor(M*比例)`。不足一例向下取整，即使重复k也保留各点。排序、比例和取整不看GT，不按结果挑最佳阈值。

各点全部报告：送审数及实际比例、自动覆盖(N−k)/N、残留false-S数/原面板non-S分母、自动S假发现率、自动子集MCC与PA、送审真实S数及三类构成。自动子集MCC/PA调用现有项目metrics接口；不另造评价器，不把送审算正确，也不把未送审分母偷换为全量正确率。

随机参照为从同面板原判S的M例中等概率不放回送审同样k例。若其中原false-S有K例，超几何期望为送审false-S=`k*K/M`、残留false-S=`K*(1−k/M)`、送审真实S=`k*(M−K)/M`。只报告这些解析期望，不进行随机抽样或将期望混淆矩阵当成期望MCC。
