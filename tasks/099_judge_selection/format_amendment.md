# 099外层JSON围栏工程修正

在首例四模型预检后、任何目标正确率/MCC或GT连接分析之前，发现Flash返回完整Markdown json代码围栏。请求成功、内容未截断，原严格parser仅因外层围栏拒收。该现象按响应结构判断，不读取目标GT、旧对错或选择有利标签。

原common099.py、协议、全部请求、冻结样本与费用记录不改。新增parse099.py仅对覆盖整个最终content的` ```json ... ``` `或无语言围栏去掉最外层，内部必须是原始完整JSON并按同一严格verdict、重复键规则解析；不搜索正文标签、不补括号、不修破损JSON、不引用reasoning_content、不调用模型。统一对四模型所有请求应用；无法完整解析仍invalid。原严格有效性/标签并列保留，给出严格共同分母及推荐变化敏感性对照。

主评价使用经这项共同格式规范化后的模型直接verdict。该修正不改变医学三分类口径、推理配置、样本、规模或模型选择阈值，不重发任何HTTP200，不按结果扩量。原始冻结SHA仍严格核验；新解析器单独在首次质量分析前锁定指纹，不放宽旧校验。
