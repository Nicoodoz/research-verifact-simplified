# GPU资源补充核算：96GB主方案与80GB后备

模型卡/权重索引可静态核对，吞吐与峰值显存仍待预跑。本页不把静态算式写成实测。

Qwen3.6-35B-A3B的40层、256路由专家、hidden2048、expert intermediate512，对每层gate_up与down均做r16普通LoRA时，仅专家适配器约922,746,880参数。若PEFT将适配器保留FP32，参数＋梯度＋Adam两状态约13.75GiB；原始BF16权重约66.97GiB，合计约80.72GiB，尚未含额外非专家LoRA、激活、CUDA与临时工作区。实际Unsloth布局/dtype须从预跑trainable_parameters和load记录核实，不能按激活3B估显存。

因此96GB主卡有测试价值但并非承诺一定容纳最长输入；A80080GB不能被保证能以相同r16/BF16/全专家覆盖跑完该MoE。若只能提供A800，优先使用已准备的9B＋3.8-27B后备包，同数据同训练与三臂评价；3.6保留为未解决候选，不改4bit/CPU卸载或缩短reference冒充等价方案。选择硬件分支在GPU调用前记录，不凭训练成绩切换。

当前脚本为恢复每64条保存一次，256和512检查点保留。考虑MoE适配器与optimizer、两模型权重、独立环境及一份结果tar备份，建议**至少320GB可用持久磁盘**。这更新早期200GB粗估；不删除任何未备份检查点来凑磁盘。存储实际价格须在收到实例后计入60元；优先含足够免费磁盘的实例，不能默认扩容免费。关机不等于付费存储停止，执行者须在数据回传并核对后处理本次付费存储，不删除未备份资料。

96GB主方案数据包为gpu_bundle.tar.gz；80GB后备为gpu_bundle_a800.tar.gz。两者均在本地私有目录，未上传、未下载权重或租GPU。根据用户实际提供的卡只采用一个分支，共用本轮累计60元/8小时账本。
