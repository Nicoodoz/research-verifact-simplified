# 095 普通服务闲时时段补充核实

初次查到的中文模型页列出人民币忙/闲时费率，但未显示时间定义，因此首版执行器按忙时上界计账。机密MaaS是不同服务，未使用它的时段冒充普通服务规则。继续查询后取得普通服务官方公告：

- [阿里云 Model Studio 0731 调价公告，2026-08-14发布、08-17生效](https://www.alibabacloud.com/en/notice/model_studiodeepseekv4flash0731_price_increase_notice_831?_p_lc=1)：明确同一0731模型的峰谷计费，北京/Global行在适用范围，UTC+8每日22时至次日08时为闲时，其余为忙时。该国际公告给美元价，本任务**不兑换美元计费**。
- [中文0731模型页](https://help.aliyun.com/zh/model-studio/deepseek-v4-flash)：北京实际模型输入/输出/缓存输入人民币忙时3/9/0.3，闲时1.5/4.5/0.15，单位百万token。任务调用返回model也须等于该快照，实际配置为北京普通直连。

以上联合确定人民币时段目录价。不是优惠券、赠金或假定全部缓存命中。缓存仅按usage中实际cached_tokens；未知usage、缺时间或跨忙闲边界全部仍按忙时保守界。未取得账户结算账单，目录价usage估计不冒充银行实扣。

首版baseline进程不热改。待正常阶段边界退出，保存其原费用记录，使用独立pricing095.py重算已知usage：仅响应开始与结束均在同一个闲时窗口且耗时合理的请求采用闲时价。每次发送前仍按忙时最大token费用原子保留；HTTP0/未知不释放。所有阶段、旧尝试与新尝试继续在同一个SQLite总账内，硬上限150、通常首次请求130、baseline阶段80不变。

原request/receipt、首版协议、runner冻结与阶段审计原样保留。费用重新对账属于取得官方计价依据后的工程修订，不改变科学请求、ID排序或成绩选择。若更低的已核实目录价允许继续补齐B，沿原固定队列恢复，不重发已有HTTP200。
