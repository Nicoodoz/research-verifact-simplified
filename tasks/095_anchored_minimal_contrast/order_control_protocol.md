# 095 条件式顺序控制（任何候选结果前登记）

若首轮达到继续/边缘条件，在扩量前增加一次最多24条的有限顺序控制；否则不调用。它不是新候选，不进入primary选优，也不改变扩量样本或继续的数字阈值。

从首轮可部署候选中按固定哈希各取自然12、富集12（不足一面板则不跨面板借例）。不按本轮正确/错误或救回选取。复用首次C；新增C_order仅改变用户JSON中字段次序为proposition、reference、auxiliary_anchor_excerpts、alternative_hypothesis，其余系统文本、字段值、生成设置全部相同。原C的canonical字典次序使alternative字段较早出现。本控制检验对展示次序的敏感性，不宣称覆盖所有提示扰动。

报告24条的raw/final逐例一致、救回/伤害、分数边界和输入token/费用。若关键正向病例显示严重顺序依赖，扩量前需在来源审查中说明其不稳定性，可停止，但不得挑更好的顺序替换primary。预计闲时费用约0.4元，计入方法共享45元及总150元；预算不足则列未执行，不挤占主配对完整性。
