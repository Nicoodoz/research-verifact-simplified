## 哪些是历史材料

本目录编号执行提示词和任务计划是当时用户授权的快照，不是等待自动执行的任务；各次后来的用户授权/结果见任务索引。论文旧v1/036稿不是当前稿件。论文笔记、数据集笔记、单病例导读和动态切分旧项目资料用于阅读，不提供当前进度或新增医学GT。skillpaperreading/skillpaperwritingrevision是可选写作材料，不是当前任务执行授权。

docs/sources是引用来源/上游代码快照，不随本项目状态改写。outputs中的协议、报告、README/CURRENT、审计附件和各任务冻结protocol继续保留形成时内容；不要把其中的旧暂停、阶段预算或下一步当现行指令。当前导航更新与冻结历史分开，详见[维护报告](maintenance/2026-09-27_sync/report.md)及[旧导航快照](history/2026-09-27_before_sync/README.md)。
