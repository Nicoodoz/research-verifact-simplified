## 五、评价：既判断信息贡献，也判断可用性

复用公共`evaluate/paired_compare`。主表沿项目格式：实验配置｜MCC｜PA｜正确数｜错误支持数，并增加Macro-F1、各类P/R/F1及完整混淆矩阵。

### 固定判定层

主机制分析看raw verdict的配对正确性、MCC、各类错误与预测变化；系统分析看同一Frozen PriorG。U0和固定U2是辅助，不在结果后选最漂亮的层作为主结论。

- 报告raw与U0是否逐例相同，不能默认相同。
- 自报分数只作score诊断，不称其为token概率或校准概率。
- 以患者为配对重抽单位，报告区间、患者胜负/等权PA，并说明区间没有覆盖模型调用的全部随机性。
- 主比较F4－X4、F4－CL4与必要的F4－B事前登记。多比较显著性结论要处理多重性或明确为探索区间，不能挑一个小p值宣称机制成立。
- 错误支持同时报告数量、占真实non-S比例和占全部病例比例，分母写清。
- 不沿用3个百分点风险否决，不要求所有指标都提高，也不允许将明显NS/NA崩塌包装为“小代价”。

另列同ID作者原VeriFact历史预测、已有B/F4历史值，但注明历史/非同期/不同系统；本轮主因果比较使用新四臂。

### 有效性与输出层归因

保留完整分母与四臂共同核心有效敏感性。对于所有变化，先按以下顺序分类：

1. 任一臂核心无效、截断或fallback相关；
2. 双方核心有效且raw正确性变化；
3. 双方核心有效、raw判断不变而最终标签因分数映射改变；
4. 其他双边错误类型切换或无变化。

不将无效raw、缺失score与fallback混成评分边界效应。完整统计救回和伤害，不能只展示成功病例。抽查的reason只用于解释输出说了什么，不用于重新裁定医生GT或模型内部原因。

### CL4成本与是否值得保留

对四臂报告prompt/completion/总token、输出截断率、单例原价、实际费用和调用时长分布。不由一次并发时长推断可靠的端到端加速。

不把“CL4－F4区间跨零”说成等效或非劣，不用不显著代替证明。无需在本轮临时发明非劣界限；直接报告区间允许的性能损失/收益和节省幅度。即使CL4有吸引力，也先作为待确认的紧凑候选，不自动替换默认系统。

## 六、事前限定结论，避免再靠讲故事挽救阴性

最终至少区分以下情形：

1. **F4相对B有收益，且稳定优于CL4和X4：** 支持在本条件下，完整且正确关联的示例证据有额外价值；仍不证明学会了具体推理技能。后续才有依据研究证据关系导向的示例构造。

4. **CL4/X4与F4差别小但区间宽：** 结论是信息不足，不能宣称正确关联不重要。按原协议结束，不继续扩变体或重复到得到显著性。
5. **本轮F4对B不再有正向信号：** 如实报告患者/批次异质性；不抹掉084旧结果，也不靠合并旧数据隐藏本轮结果。

本轮最多建立一种受控机制证据或一个紧凑候选。不要把F4、CL4、X4写成已经发现了新的通用算法；不要把文献中的结论当本项目结果。
