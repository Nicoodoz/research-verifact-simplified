## 五、主方法：提取“原理由说了什么”，不是让第二个模型重新判病历

### 5.1 原生文本通道，尽量零API

主文本为原`reason`及checks中的`relevant_evidence`、`supporting_case`、`opposing_case`等实际叙述。`claim_summary`不作为理由增量，`overall_assessment`中重复的最终结论单独处理。

冻结清洗规则：移除显式三类评分、作为枚举值出现的标签及重复的最终判决提示，保留其解释内容和临床否定／时间／条件语义。不要把所有“not supported”相关句子整段删除而丢掉原因，也不要删除所有数字而破坏剂量／时间信息。用训练侧小样本检查规则；报告清洗比例。未清洗版仅作诊断，不因其得分更高而事后替换主方案。

使用一个本地已有、可冻结的文本编码器，强正则线性学习。优先复用现有本地embedding，不能把reason误套为已有claim embedding。降维、标准化、词表等有拟合步骤的操作只在训练折进行；固定每个文本块不超过约16–32维，不搜索多个编码器。没有可用本地编码器时，用训练内拟合TF-IDF＋固定维度SVD作为降级，并在评价前固定。

### 5.2 原理由的细粒度结构化提取，主要收费项目

选择一个现行已授权供应商下的固定低成本非thinking模型；核实模型ID、实际支持参数和价格后冻结，不因输出与GT不一致换模型。输入仅为清洗后的原生reason/checks，**不提供GT、原score、最终标签、患者／作者／任务标识、候选正确性、完整claim/reference或其他病例**。

这样提取器只能整理原文本，不能借完整病历做第二次核验。不要把从原理由抽出来的字段叫做经过医学验证的真实关系。

建议输出一个紧凑的论据集合，最多约6项，每项有：

- 立场：支持该命题／反对该命题／未决；
- 依据类型：明确记录、语义等价或转述、推断、要求显式措辞、明确反证、事实缺失、相关性不足、其他、未提到；
- 涉及维度：事件／计划执行状态、时间、否定、确定性、数值、归属、范围、其他；
- 原理由中可以逐字定位的短引文。

仅在原文本明确陈述时记录对应状态。例如“理由没有谈到时间”应是`not_mentioned`，不能默认`time_matched`；“记录没有写完成”不等于“记录明确说没有完成”。不自动推导所有要求都满足、不生成新的最终S/NS/NA判决、不输出第二组三类概率。

具体字段可根据真实原始schema在**训练侧**简化一次，然后冻结；避免几十个自报0–100轴。每个非缺失状态都应有来源引文，无可定位引文则该特征为缺失。引文核验只证明抽取有文字依据，不证明原reason正确。

从同一份提取结果生成两组特征：

- 粗聚合：支持／反对／缺失／不确定论据计数、少量引用与格式统计；作为029式粗信息的当前任务对照，不声称严格复现029；
- 细粒度：依据类型及“依据×维度”的少量事前定义指示特征，区分例如“要求显式措辞”与“事件完成事实缺失”。总维度保持低，不按GT添加特征。

不设“任一要求不支持就拒绝S”的硬规则；不新增临床gold。引用合法性是质量特征，不是诊断正确性的证明。

## 六、必须完成的对照：证明增量究竟来自哪里

冻结一个低容量下游模型族，优先L2正则多项Logistic。所有学习对照使用同一训练集、权重、患者折及小型正则候选集（例如3个值），不再追加XGBoost／MLP搜索。允许从三类中正常输出，不仅对原λ候选设置放行门。

至少比较：

| 编号 | 输入／用途 |
|---|---|
| H | 原F4 raw、U0、U2、Frozen PriorG，以及B＋Frozen PriorG；均保留历史冻结规则 |

| C | N＋claim文本表征；控制命题主题／措辞本身的可预测性 |
| T | C＋原reason/checks文本表征；检验未结构化原文本增量 |

| R | C＋细粒度原生理由特征；本轮预登记主候选 |

可给N补一个事前固定的低维二阶log-score特征作为更强分数对照；一旦采用，各扩展臂也使用同样的数值基础，不能故意给评分基线更弱的拟合能力。

如果raw verdict与U0逐例相同，如实写明，没有额外信息；不能因其他历史条件下raw较稳定就预设其本轮有增量。

主超参数只用14名校准患者分组验证选择；scaler、SVD/PCA、词表、特征筛选和模型都排除留出患者。每个方法使用相同规则，推荐按源比例加权的OOF NLL选正则，MCC/风险同时报告。不能在532条上选模型或阈值。首轮冻结比较完成后不重拟合补救。

## 七、两项必要的“不是假增量”检查

1. **消除标签复述的作用。** 主R/T使用已清洗文本，N/C已有raw verdict。若只有未清洗版本提高，标为“可能主要重编码原答案”，不是细粒度关系贡献。
2. **病例对齐负对照。** 主模型冻结后，将评价理由特征在不使用GT的同raw／相近分数组内按固定hash置换，保留数值输入不变。只作一次诊断，不能按置换结果改模型。对齐理由优于错配理由才支持病例特异信息解释；若无差异或样本不足，如实限制，不把此检验当成内部因果证明。

同分异标签分析是次级诊断：在完整评价后按原score分组，检查R是否比N/G正确区分这些病例、同时是否伤害其他病例。不能事前根据GT只挑冲突案例做主训练／测试；不能将共享病例形成的成百上千个pair当作独立样本。

原生`reasoning_content`只作为预登记的低成本辅助：先清点，有本地计算条件时按固定截断／分块规则做文本表征对照，训练内降维；不通过收费大规模总结整段thinking挤占主实验，不把它当忠实内部思维或独立医学真值。此辅助可以未执行，但必须说明，不能混入主R后仍称reason/checks方法。
