# 27项外部文献筛查及与VeriFact的适配判断

核查日期：2026-09-28。本文不包括作为主阅读材料的VeriFact本身。

这是一份有明确范围的定向综述，不是系统性文献综述，不宣称穷尽文献。阅读分层逐行标出：正文重点核读与摘要筛查不是同一证据等级；未核验的代码不能写成已经复现。论文自报增益均不外推为本项目预计提升。

“结论”列是针对本项目（医生三标签、固定claim、冻结核心Judge、有限费用）的研究判断。

## 最重要的阅读顺序
先读VeriFact原论文与代码差异，再读L06 FactEHR、L11 Alignment Bottleneck、L07 ProgramFC及其代码、L08 GraphFC、L09 DOSSIER、L10 CARENLI。L04/L05/L18/L23支持源文依赖路线；L12–L16是防止重复自纠错试错的正反参照。L24–L27用于解释接口和评分风险，不应变成新的调分主线。

## 不能混淆的任务与指标
固定病例三分类正确率、回答覆盖率下的准确率、事实精度、摘要评分相关性、置信度校准误差、引用合法性是不同目标。外部论文在某一个目标上成功，不等于本项目PA/MCC会提高。
