# 一、prompts目录（作者用到的提示词）

1. `prompts_llm_writer.tar.gz` ：用 Llama-3.1-70B-Instruct 生成 LLM-written BHC 时使用的提示词

2. `prompts_atomic_claim.tar.gz` ：用 Llama-3.1-70B-Instruct 将BHC/EHR拆分为 Atomic Claim 时使用的提示词

3. `prompts_proposition_validity.tar.gz` ：判断某个 proposition 本身是否构成一个有效、可以判断真假的命题时用的提示词 ？有些句子本身就分不出Supported，Not Supported，Not Addressed

# 二、propositions 目录（待核验文本 + 人工 Ground Truth）

1. `propositions.csv.gz` ：13,070 条 propositions，包含 sentence 与 atomic claim 两种命题；核验标签为Supported、Not Supported、Not Addressed，并非全是atomic claim。包含：

   - proposition text；
   - 来自 human-written 还是 LLM-written BHC；
   - 是 sentence 还是 atomic claim；
   - 它所属的完整 source BHC；
   - MIMIC patient ID；
   - admission ID；
   - 其他 proposition metadata。

2. `human_verdicts.csv.gz` ：含有医生查完整患者 EHR 后给 proposition 标的标签：Supported、Not Supported、Not Addressed。ground truth

3. `proposition_validity.csv.gz` ：存储：proposition 本身是不是一个**有效的、适合被事实判断的 proposition**

# 三、reference_ehr 目录（Patient Reference EHR也就是核验 BHC 的“证据库”。）

1. `ehr_noteevents.csv.gz` ：100 名患者的：**MIMIC-III NOTEEVENTS，**构成的 reference EHR。discharge summary 被排除了

2. `ehr_noteevents_pdf.tar.gz` ：医生标注时实际看到的 EHR。 ，内容同ehr_noteevents.csv.gz，只是pdf人类易读

3. `subject_ids.txt` ：这次 VeriFact-BHC 选中的 **100 个 MIMIC-III patient IDs，即100个患者在MIMIC数据集中的编号是什么**

4. `admissions.csv.gz` ：100个患者什么时候住院、是哪一次住院这类住院事件级信息

# 四、verifact目录（原作者 VeriFact 系统实际跑出来的 AI 实验结果 + 配置。）

1. `verdicts.parquet` ：1,437,100 条 AI annotations，每一行大致是在表达：

   ```text
   某一条 proposition
   +
   某一个 Judge
   +
   某一个 retrieval 配置
           ↓
   VeriFact 判断结果
   ```

2. `reference_payloads.parquet` ：作者做实验时，VeriFact Judge 真正看到的 reference context

3. `model_metadata.csv` ：保存九个 LLM-as-a-Judge models 的精确元信息，有 tokenizer 等

4. `rater_configurations.csv` ：一次 VeriFact 实验设置是什么，fact_type、retrieval method、`top_n`等等信息

5. `experiment_matrix.csv` ：作者做过的实验设置矩阵
