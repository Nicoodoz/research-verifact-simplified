# 077 固定示例的判别信息与同风险表现

## 决策问题

F4究竟增加了类别判别信息，还是主要改变给分尺度？076已经拆开raw、PriorG和fallback，但两个固定判定点不足以回答排序信息是否增加。077只补这一缺口；不是重开054–064的新环境自适应，也不以本轮评价GT选择部署阈值。

## 计算前固定的口径

- 只比较B和固定F4。沿用076的7个执行阶段，及重复ID取最早/最晚一对的两种去重规则；不按正确与否选轮次。每对只用两臂共同核心有效，完整系统成绩引用076，fallback不制造score。所有排除ID、来源和分母保存。
- 新增诊断指标为三组二类AUC：S–NS、S–NA、NS–NA。仅在对应两种医生GT的病例中，使用log(max(p_a,1e-6)/max(p_b,1e-6))排序；较高表示更偏第一类。同分计0.5，分数按12位小数处理数值同分。每类乘固定正权重只给该log比值加常数，因此不改变这种AUC。三组等权平均仅为描述性汇总，不是三分类准确率。缺类则该组未定义，不补0.5、不把其余组平均冒充完整macro。
- 配对不确定性采用1000次患者cluster bootstrap，种子0–999。患者整体抽样，两臂共享抽样；类别缺失的重采样明确排除并报告数量。附逐患者留一、human/LLM与按历史任务块留出（071+072、073、074、075）敏感性，不把这些当新的独立确认。
- 同风险主诊断：固定原PriorG的NS/NA相对权重，仅遍历Supported整体偏置的全部精确切换状态。每个状态仍输出完整三分类标签；指标调用项目公共evaluate，分母完整，保留NS/NA错分成本。风险定义为false-S/(真实NS+NA)，收益为总体正确数/N。仅比较S召回不能替代完整正确数。
- 在风险上限0%、5%、10%、20%、30%、100%处列出各臂允许状态中的最高正确数，并给出全部曲线。主摘要为0–20%风险预算范围内的平均正确率差；这一区间是预先选定的低风险诊断范围，不是临床安全标准。全范围曲线同时保留，避免只挑有利阈值。
- 同时给出确定性状态上包络和相邻工作点随机混合的上包络，后者可公平比较分数同分/台阶位置不同的模型。两者都使用评价GT计算，是经验oracle式诊断，不是可部署选择器；随机混合只是期望值，不宣称每个病例能选对。bootstrap每次重新构造包络，区间不消除oracle选择乐观偏差。
- 以未修正的NS/NA相对权重重复同风险诊断，作为固定机制敏感性，不在两种曲线之间挑赢家。不会搜索其他NS/NA权重、拟合校准器或设计新算法。类别AUC另作不依赖这两个固定边界的判断。
- 类别条件的log比分数改变量、同患者内部AUC作为补充，防止把患者/作者组成差异或统一尺度偏移误解成新判别信息。分层样本少时只描述，不强行推广。

## 结束决策

不要求全部类别/指标同时提高，也不把区间跨0自动当失败。结合增量幅度、两种去重规则、患者和任务块影响、同风险表现决定：

1. 没有有意义的排序/同风险增量，或由单一阶段/患者推动：停止当前F4方法开发。
2. 出现较一致且有实用幅度的增量：仅支持下一次简单、患者隔离的适配验证，不证明新环境无标签适配已可行。
3. 方向混杂/证据不足：明确未决，并按毕业时间目标暂停，不自动扩大队列或重发成功请求。

这是针对已经暴露development数据的事后诊断。没有新盲测、没有临床新增GT；不能把最优曲线成绩当最终测试。形成研究决定及可用于论文的表述，详细实现由本任务确定。
