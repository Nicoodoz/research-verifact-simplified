基础映射是log原分数＋log(参考类别比例/校准样本比例)，随后仅添加小幅类别偏置。避免把任意LLM分数当作已经校准的概率，不声称先验修正的贝叶斯假设已满足。旧G不作为新适配的锚点：078/079显示它在本队列没有独立标签贡献；保留旧PriorG作为最终参照。所有候选仅使用B/F4三类分数。

四个事前规定的配方及一个零改动参照：

1. BASE：仅按本次实际校准类别比例作固定先验映射，无新增偏置。
2. WNLL1：在**已追加先验映射的最终logits**上，按参考类别比例加权NLL，只拟合S偏置。
3. WNLL2：同上，拟合S与NS两个偏置，NA固定0。
4. WMCC1：直接最大化按参考类别比例加权的最终MCC，只选择S偏置。
5. WMCC2：同上，选择S与NS两个偏置。

偏置范围统一[-ln4,+ln4]。WNLL沿用0.01×偏置平方均值的正则强度，使用有界凸优化；不搜索正则。WMCC使用固定{-ln4,-ln2,0,ln2,ln4}，分别5/25组，按加权MCC、加权Macro-F1、加权PA、离BASE的距离顺序打破并列。此为训练内参数拟合，不在352条上搜索。无新温度、门控、分组规则或模型。

训练目标权重为pi_ref(y)/pi_train(y)，归一化后各GT类权重总和等于参考比例；评价GT不会用于估计目标比例。
