# 014：Qwen3.8-27B与V4-Flash固定证据比较

**Qwen3.8-27B值得继续作为较小、便于私有化探索的研究模型；当前不直接替换V4，也未证明正式非劣。**

C48已知的条件/身份等信息损失继续保留。本轮比较模型对这套实际证据包的处理，不能外推为完整EHR下的能力排序，也不把发布reference当医生gold evidence。

主对照提前选定010完整C48 canonical结果；009旧C48只作非同期敏感性。010 V4于2026-09-15 02:51–03:38 UTC运行，Qwen于2026-09-15T13:50:52.921323+00:00至2026-09-15T15:27:03.862854+00:00运行。相同字符串不等于相同tokenizer/模板或计算量，服务未提供不可变权重指纹；小幅差异不能孤立归为模型能力。已有009→010同C48 body发生80/650次标签变化。

## 7. 是否值得成为私有化研究模型

**建议继续保留Qwen作为研究候选，优先关注人写NA/NS区分及条件、事件关系的证据要求。** 理由是总量表现已接近、完整650条均能产生有效输出，并有可回查独有改对，模型总权重规模也明显较小。研究价值在于有机会在较易部署的模型上研究明确问题；本次换模型比较本身不是论文创新。

当前不自动追加prompt、重排、微调或013路线的v2/v3，不消耗剩余患者。NA只是标签层面的集中差异，24例不足确定总体主因或可修复比例。若后续另行立项，应先给出可归因的新依据、同时保留NA改对与退化及S类代价，再决定是否值得使用剩余开发患者确认。

官方模型卡给出Qwen语言模型27B稠密参数与Apache-2.0开放权重；V4-Flash为284B总参数、13B激活的MoE。Qwen总权重规模明显较小，有私有化研究动机，但这不意味着激活计算量更低或本地更快。这里没有下载权重、测显存/速度或评估量化损失，也不能确认API与某个公开checkpoint完全等价。[Qwen模型卡](https://huggingface.co/Qwen/Qwen3.8-27B) · [V4模型卡](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash)

Qwen官方非thinking推荐采样包含temperature=0.7等设置；014按用户要求沿用V4 temperature=0，未作Qwen专用调参。本结果限定为固定配置下的可比baseline，不是Qwen的能力上限。任何后续本地部署/训练或新实验另行立项，不消耗剩余development或reserved test。
