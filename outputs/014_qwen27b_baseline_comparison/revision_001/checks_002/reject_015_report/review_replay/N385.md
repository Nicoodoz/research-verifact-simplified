# N385：疼痛作为管理重点的范围仍需解释


## 直接观察

原包同时详细记录镇痛、房颤、创伤、肺肾管理。仲裁与无候选都按不是唯一或主要重点给NS，原GT为NS。仲裁reason额外说equal attention，文本并没有量化各系统注意力相等。

## 解释与限制

这条严格范围与GT一致，但N528/N216相似严格要求会退化，不能据个案制定一律严格规则。

原初始三方分歧；the focus不逐字等于sole focus，未新增医学GT或管理优先级裁决。
