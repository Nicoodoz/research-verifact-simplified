# 主Judge运行前的一次工程修正

32次问题生成均结构可解析、待证字串未直接出现在问题中，但语义检查发现“某事件的结果是什么”预设事件发生、以及少数问题丢失事件范围。仅字串隔离不足以宣称语义隔离。

保留原始生成回执及questions.jsonl。对所有保留问题统一加上：不假定事件发生，先确认记录中有什么；无法定位事件/上下文则报告证据不足。这是一次固定的非生成规范化，不改目标取值、不重发成功生成、不改变V/Q之间的唯一可见性差别。6条无法保持合理识别范围的问题被拒绝，不做逐条人工改写。自然16/20、机制10/12可操作，满足事前80%/75%工程条件。

执行者语义检查仅看原claim和生成问题，未查看GT或旧预测；不是独立审计。单目标问题不会遮掉原claim中所有其他属性，隔离主张限于登记的待证取值；其他上下文仍可能引导取证，最终报告不得声称绝对消除了确认偏差。自然2个非S、机制三类均衡的原冻结样本不替换。

这仍是经执行者审核的问题可行性原型，不声称已经验证了无需审核的全自动部署。人工审核成本另列，不能只报API费用。
