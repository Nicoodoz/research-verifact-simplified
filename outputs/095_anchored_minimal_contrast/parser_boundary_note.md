# 冻结解析规则与raw有效分母

最终独立复核指出，9,034条“raw有效”是沿历史冻结解析契约得到的集合，不等于另外31条响应文本完全没有出现原生verdict片段。

例如`8c3f17b6`开头的病例发生输出截断，文本已有verdict字段，但label_scores字段未完成。历史`core024.partial_object`对未完成核心字段采取严格处理，因此该回答在本轮仍不进入raw有效集合。具体完整ID、回执哈希及独立检查见[最终独立复核](../../reviews/095_anchored_minimal_contrast/final_review.md)。

本轮没有在看到标签或成绩后改变解析器、手工补答案或重发成功请求。统一表保留原生回执身份、finish_reason、解析错误和无效状态；core 8,997、raw 9,034、成功覆盖9,065的原口径均不变。

这限定了raw结论的分母与解释：应写“冻结解析规则下有效”，不能写“其余响应未产生任何原生判定”。不把少数可见字段片段自动当成完整、合格的结构化输出，也不把严格解析失败解释成医学核验失败。
