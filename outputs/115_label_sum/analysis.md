# 115执行前判断：先回答训练目标问题

本轮选择`label_sum`，即106已准备但尚未做真实分类验证的全局归一标签值目标。它是一次范围明确的训练诊断，沿用107的196条与50步，只改变标签段归一方式。先做一个候选和完整500评价，结果无价值就停，不叠加114样本更新或再搜类别权重。

## 唯一可直接核查的目标差异

原196条的标签token序列为：S `[33490]`，NS `[2536,47338]`，NA `[2536,8904,290]`。标签长度分别为1、2、3，原值段损失是`sum(CE)/L`。这使每个类别的标签路径NLL分别带1、1/2、1/3因子；在首个S/Not分支上，直接CE系数合计为83和48。系数是目标定义，不能当作9B学到的先验概率。

候选只把值段改成`sum(CE)/(360/196)`，其他答案段平均CE不变。固定常数来自83×1＋62×2＋51×3=360，不接触500条成绩。每条相对原目标的标签段力度变为S0.5444、NS1.0889、NA1.6333；全196条平均总力度仍为1。这不是额外false-S代价矩阵，确实会改变三类相对梯度；也不是完整JSON+EOS统一NLL。

作为反例，若所有输入完全不可区分、模型只能学习一个三类分布，最小化`-Σp(y)log q(y)/L_y`得到`q(y)∝p(y)/L_y`；固定缩放的路径sum则得到原p。用原比例代入，前者约为.634/.237/.130，后者为.423/.316/.260。这是目标性质的玩具推导，**不是107实际预测分布**。在标签可由输入完全区分、模型容量足够时，两目标都可达到零分类误差；有限LoRA是否受益必须靠本轮真实评价。107已能拟合训练NA的历史诊断也反驳“均值目标必然学不会NA”。

## 少量原论文及反证

[T5，Raffel等，JMLR 2020，§2.4及§3.1.2](https://jmlr.org/papers/volume21/20-074/20-074.pdf)把分类写成标签文本生成，采用teacher forcing和交叉熵，测试使用greedy。这提供成熟生成式标签监督的背景；没有证明本项目特定的1/2/3长度修正有效，也没有比较本轮的分段loss。本文的逆长度分析来自项目实际代码与代数推导。

[Schick与Schütze，NAACL 2021](https://aclanthology.org/2021.naacl-main.185/)展示小模型可通过任务文本化和梯度优化取得少样本效果。它的cloze/PET、无标签资料使用和模型类型与本项目不同，不能借其成绩承诺临床核验收益。本轮不改verbalizer、生成新标签或复制其多阶段流程。文献用于确认方法来源及边界，不用于替代500条实测。

## 为什么只值得一次受限试验

最可能的反结果是NA召回提高却损失NS或正确S，仍然只移动决策倾向。全局归一避免额外改变平均标签段尺度，但没有让分类表示自动变好；单seed、历史硬件对照、196条筛选偏差和完整EHR GT与实际reference范围的差异均保留。若无综合收益，就结束此目标配方，不再微调常数、采样、阈值或epoch。

即使通过事前门槛，当前证据也只够建议必要确认，不能直接成为默认升级或论文原创算法。后续应优先验证保留下来的实际收益与同模型公平对照，而不是再扩模块。本轮具体数据、预算、停止规则和执行边界见[协议](../../tasks/115_label_sum/protocol.md)。
