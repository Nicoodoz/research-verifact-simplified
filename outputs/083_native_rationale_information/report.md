# 083：原生理由是否提供超越三分数的可迁移信息

**研究决定（2026-09-26）：停止当前“从原Judge reason/checks抽特征再分类”的版本，不更换默认B＋Frozen PriorG。** 完整原生回执可用，结构引文大多能逐字定位；但在同459条训练标签与14患者折外选择下，细结构R比三分数＋raw的N、命题控制C、直接理由文本T、粗结构G均少判对，且较F4＋Frozen PriorG明显增加错误支持、损失NS识别。病例对齐负对照未显示细结构有可用的病例特异增量。这里否定的是本次表示、类权重、低容量学习器和已暴露development队列的组合，**不能证明理由原则上没有信息**。

## 来源质量、训练监督与成本

原082/079/078/071的请求和回执逐条反查SHA并绑定到同一回答的verdict、三分数、reason、checks、thinking；不存在用另一轮更好理由配当前分数。F4训练459、旧352、新180、重复24共1015条，**全部reason/checks/thinking非空**；评价F4的8条评分核心无效仍保存理由，但最终按预定U2回退。通常checks为五节：`claim_summary/relevant_evidence/supporting_case/opposing_case/overall_assessment`；旧352中有2条checks采用非标准dict，按缺失节处理。主输入只保留reason和中间三节，排除claim摘要与最终结论节；清洗186条中的189处显式最终判决短语，保留部分的字符数654752→652774（约−0.3%），没有裁剪超长段落，保留临床否定、时间和数值。全1015个JSON抽取响应可解析，逐字引文与枚举核验后接受4745个论据、拒绝500个（枚举非法328、引文非原文连续子串172）；仅新180中1条没有有效论据。引用有原理由文字依据，不证明原理由的医学真实性，也没有“未提及即匹配”的默认值。

主训练459条／14患者为082 R∪E的347条与079旧112条，GT S/NS/NA=323/57/79。统一类权重目标只读这14人的历史源标签1218条（982/88/148）；同一459条标签已包含于源集合，B/F4两答不算两份标签；留一时从源比例和训练比例均排除留出患者。旧112为类别富集材料，R/E为不同机制，类权重不是已知纳入概率的精确校正。所有学习臂相同监督预算。提取类别并非全为零：训练侧明确记录977、事实缺失409、明确措辞要求131、反证143条；事件状态724、时间273条，完整分布见[类别台账](structured_distribution.json)。校准折外加权NLL在选中强正则下N/C/T/G/R为0.3831/0.3936/0.3784/0.3899/0.3947；T训练侧小优势到旧／新评价均转为较高NLL，不能叫迁移增量。此共同权重也使所有学得模型偏向S，但R比同权重的N/G仍更差，不能把R的全部失败归于权重一项。主环境不含torch/transformers，未安装新环境；文本通道按事前降级为训练折内char TF-IDF＋24维SVD，不把reason套用旧claim embedding。thinking_content虽存在，P只用前2048字符且未并入主R，不把它当忠实内部思维。
