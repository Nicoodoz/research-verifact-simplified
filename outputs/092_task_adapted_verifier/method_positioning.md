# 方法定位与文献边界

092的可检验增量是“相同C48与头部结构下，医生监督是否应更新文本encoder”，不是提出attention pooling、交叉熵或部分解冻这些操作本身。全量9065 OOF已完成：Fine较Frozen净+326、MCC +0.0722，但NS召回仅8.95%。相对原作者PA更高、类别风险更差；一次融合较偏置对照有有限增量，仍未升级默认B。论文价值是有完整模型实现的受控任务适配证据及其风险边界，不是未经证明的通用新算法。

MedNLI已研究医生标注的临床自然语言推断和迁移学习。因此不能声称本轮首次让医学标签监督文本模型；本轮差异是使用VeriFact-BHC的完整记录三分类标签监督有限检索包核验，并与生成式核验器的同ID结果比较。MedNLI没有在本任务运行，也不把另一数据划分的论文数字放到主表。[Romanov与Shivade，EMNLP 2018官方页面](https://aclanthology.org/D18-1187/)。

DeBERTaV3是既有预训练编码器，本轮复用其NLI checkpoint，只在医生标签上更新顶部一层，并没有重新实施其预训练算法。模型家族信息来自[原论文](https://arxiv.org/abs/2111.09543)与[Microsoft官方实现](https://github.com/microsoft/DeBERTa)；实际权重身份、原NLI数据与许可证以本地032锁定model card和manifest为准。OpenReview网页本次触发验证，未声称读到其完整审稿内容。

“独立于LLM分数”只描述模型输入与训练方式，不自动证明对LLM已有信息具有条件增量。若仅有互补错误，应写为互补观察；若做融合，还需用未见患者的最终收益及偏置对照证明不能仅由重调类别比例解释。病例解释不等于医生证据充分性gold或模型内部机制证明。

同一单来源100名患者的分组OOF提供覆盖广于此前小开发队列的受控证据，但全体患者已有研究暴露，且跨折训练集合重叠。即使指标较好，也不能称为新的独立外部验证或恢复036旧holdout地位。
