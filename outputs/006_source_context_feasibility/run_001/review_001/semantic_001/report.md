## 1. 先厘清：上下文可能改变评价对象

VeriFact 正式稿说明按出院时临床状态解释命题；2025-01-28 预印本 p17 明确医生**没有原 BHC**，p35 要求逐条独立判断、不假定相邻命题依赖。因此，原 claim 字符没改，不等于加上日期、剂量或事件指代后仍对应同一个医生标签。最终正式附录本轮仍返回 403，不能把预印本冒充最终流程已经完全核实。[标注流程来源](https://arxiv.org/abs/2501.16672v1)

本轮指标衡量的是**与原医生标签的一致性**。案例阅读另检查原文理解和证据使用，没有新增医生语境 GT，不能把执行者解释当临床准确率。005 的 C17/C18 补查也未建立“只需恢复时间/剂量即可改对”：前者没有找到对应再次操作的耐受记录，后者不能明确连接来源特定剂量与反应；都不能统一归为已证实的检索失败。[文献与旧病例底稿](../../../../../tasks/006_source_context_feasibility/research_notes.md)

**未发现可据此宣称的“上下文已减少事件错配”。** N56 是正向引用例子，N45 是反向日期例子；没有预先医生标注的事件对齐 GT，不能用执行者印象给出净错配率。N01 还额外要求原 claim/来源都没有的“口服转换”。反过来，N14/N27/N28 等没有把来源中的完成/出院/姓名直接当作支持证据，说明也不能把所有输出都归为来源自证。28 例中未见明确“因为来源这样写所以真实”的证明方式，但隐含锚定、错误引用和目标扩张仍存在；这不证明没有来源污染。

**检索与判断问题同时存在。** [N50](cases/N50.md) 的实际 reference 缺少左 EVD 撤除直接片段，普通臂还用 6-14 意外脱出作反证。同患者另一个已保存 reference 却含 6-7 左侧撤除、6-12 左导管已撤除和 6-14 右导管撤除；这些没有加入 N50 输入，也不能证明“没有困难”。N15/N23/N56 的关键证据已在各自 reference 中，主要不是补充原文或扩大召回才能解决。不能从个别病例宣布某一环节普遍主导。[精确引用与跨 reference 对照](evidence_anchors.json)

## 5. 与已有工作及下一步的关系

[DnDScore（EMNLP 2025）](https://aclanthology.org/2025.emnlp-main.1205/)已把原子事实、解释上下文和可信证据分开，也有原句上下文设置；因此“加来源片段”本身不是新架构。[Molecular Facts（EMNLP 2024）](https://aclanthology.org/2024.findings-emnlp.215/)已讨论消歧与最小真值条件，并检查是否核验到正确实体。006 的区别是**患者已知、同患者内重复事件、局部 EHR、独立命题医生标签**同时存在：新增信息究竟修复理解还是改变目标，必须与标签分数区分。这个临床限制值得研究，但尚未成为已验证的方法贡献。

下一步优先验证：**保持原命题不变，恢复 EHR 证据的来源位置和局部记录上下文，检查时间/事件及支持范围是否真的对应。** 相比继续把 BHC 段落送入判断器，它较少改变待评价命题，能继续使用原医生标签，并直接针对 N25 的证据编号/文档混淆、N45 的日期误引、N50 的目标事件遗漏、N56 的跨时段引用。代价是需要先确认检索片段能否可靠连接到原 EHR；这只是推荐候选，不是已证明有效或有足够新颖性的主线。

建议先做小规模**离线可连接性检查**：用已分析病例确认能够唯一找回原记录、区分 note 日期和叙述事件日期；恢复不了就保留不确定，不猜配。若可行，再另行登记“相同 claim、相同证据 token 预算下，当前事实片段 vs 带来源位置的局部 EHR 证据”的新开发患者对照，分别统计原标签一致性、引用日期/事件错误和错误 S。上下文消歧可以保留为诊断分支，但只有能说明真值条件未改变的情况才沿用旧 GT；需新增医学语境裁决的方案当前成本较高。**本轮不启动该后续实验，也不申请补跑失败答案。**
