# 101：救回、误伤与停止原因

本轮nsna_review没有超过同模型verifact_ref。自然597条：11救回、11误伤、净0，MCC0.6376→0.6331；nsna_plain为9救回、11误伤、净−2。原文对应复核相对普通复核9救回/7误伤/净+2，ΔMCC+0.0094，95%患者区间[−0.0157,+0.0363]；不足以支持对应检查的实际额外贡献，且压力集反而净少对3条。

压力99条，review相对基线0救回/6误伤，其中4条真实NS、2条真实NA；正确65→59。plain为3救回/6误伤，正确65→62。两类各自召回阈值未必能反映全部损失，故完整正确数和MCC也必须看。

真实S原先误判NS/NA的记录仍在主表，二类复核不能将其救回；其错→错改判另存format_diagnostics.json和analysis的changes，不算救回。首次预测S集合自然402条、压力12条逐条不变，false-S分别11/144和12/99；不是风险被进一步降低。

## 格式不是主要解释，但增加了负担

首次确认review26/282回退：自然16、压力10；plain0/282。22条存在至少一处不能按冻结规则定位的引文，1条为外层Markdown围栏，余3条为空content。原始请求/回执保留，按事前规则保留首答，不事后修引文或补标签。逐条类型及finish reason见format_diagnostics.json。

在两方案复核均原生有效的自然581条，verifact_ref和review仍各490正确，MCC0.6505→0.6464；因此本轮无净收益不能主要归咎于26条回退。该敏感性删除了异常病例，只帮助解释，不能替代含fallback的主系统结果。

零API全NS/全NA诊断的自然MCC分别0.4443/0.5981，均低于两个复核。故复核并非完全等价于常量改类，但仍表现出明显NA偏移，未形成总体收益。

## 研究决定

停止本版本nsna_plain和nsna_review，不把同调用数review的净+2包装成方法突破。新增200条review净0且MCC−0.0034；plain净−2且MCC−0.0306，也没有支持扩大。重复24中plain翻转6条、review翻转2条；review第二次相对首答基线仍净0，不能说稳定优势已经存在。

本轮可保留为严格固定S集合、同调用数对照及类别取舍的阴性证据，不适合作为目前已验证的论文核心方法。停止继续叠加NS/NA规则、修改prompt、扩大上下文或靠反复重跑挽救成绩；不自动开展下一任务。未来任何新方向须有新的可检验依据和用户授权，不能仅把本轮观察再包装一次。
