# NLL下降主要发生在哪里？

来源：main40/nll_breakdown.csv；同一40名患者3675条OOF预测。分组固定依据原U2标签和原始评分，不根据温度缩放后成绩选病例。

|分组|数量|U2平均NLL|U2+T平均NLL|
|---|---:|---:|---:|
|U2原来判对|3012|0.065940|0.272909|
|U2原来判错|663|6.244585|1.969344|
|真实类别原始评分为0|260|12.736724|3.274500|
|距U2切换边界不超过0.25|276|1.117949|1.060305|

温度缩放没有修正任何标签。它提高了部分原低概率真类的概率，从而显著减轻错误样本的对数损失；同时降低了原正确样本的置信程度，后者平均NLL反而上升。
因此，本轮NLL收益更直接支持“减轻极端错误置信度”，而不是新增医学辨别能力。真实类别0分样本只是所有错误的一个子集，上表分组不能相加。
主40人的Brier从0.288112升至0.298456，配对差95%区间为[0.000685,0.019974]。不同概率评价指标并不一致，不能把NLL改善写成已经全面校准。
