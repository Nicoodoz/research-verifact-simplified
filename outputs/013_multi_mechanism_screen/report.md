## 1. 实际筛了什么，怎样避免重复旧路线

先核对main与origin/main均为`a7fca7e`、工作区干净，阅读001–012正式结果和最新审计；012已PASS。保留001/002的数据异常、评价口径与无医学evidence gold限制，不把012建议自动当正确路线。[执行前协议](protocol_001.md)固定了下列分支、选样及停止门槛。

|分支|本轮的实际改变|历史依据及刻意保留的限制|
|---|---|---|
|contract：字面主谓合同|只从原claim按首个有限助动词作表面分界，保存两个逐字跨度；要求复述原句、明确claim与证据各自断言的主体。无法分界则原样退回baseline|012 N264的patient被改为ASA；比004窄，不做通用事件/时间/状态清单。不是成熟语法分析器，不能解决所有省略和支持范围问题|
|text_guard：前缀文字修复|同患者同note，仅补切点前紧邻否定词，或180字符内未结束的条件前缀；原末端、passage身份、候选/分数不变|012 No nausea、010/011条件STRICT NPO；不加description、标题或普遍两端扩边。新增字也占8000字符预算，允许发生并记录换段|

|selector：已有候选的集合选择|同原C48候选/原分数排序，LLM仅返回真实候选短ID及优先级；从原文重建整段，最多16段、8000字符，可选同note超过2段|009/012已有候选的互补片段被末端舍弃；不是008 query planner，不生成新证据。放宽note数是集合选择方案的一部分，未单独证明LLM优于所有简单集合规则|

共同baseline是**009冻结C48实际reference＋本轮同期DeepSeek-V4-Flash普通structured Judge**。所有最终Judge的原claim、标签、模型、temperature=0、thinking=false、max_tokens=2048及普通三键输出schema一致；contract只附加上述合同操作。source/BHC和医生GT没有进入任何API。

扩候选需要新的真实重排分数，因此另设 **refresh48控制**：用同一次新重排中的分数，但限回原C48候选。这使“多给候选”与“刷新重排服务/分数”可以分开看。baseline不被悄悄换成刷新版；不混用未计算分数或填0。

## 2. 第一阶段：四个局部机制都能干预，但不等于有效方法

固定已有案例做机制检查，没有把它们当泛化成绩。8个selector、8个重排请求，加8例baseline/contract共15个不同Judge请求，全部收到有效结果；7项新增离线负向/不变性测试先通过。

- 合同在适用的7例复述了原句，N264明确区分patient和ASA，阻止了自动修成药物陈述。该单位答案是NA，仍不符合原NS；不能叫单位性能改对。N359的“prior to this→入院前”、N139的“stable→throughout”仍未解决。
- No nausea与条件STRICT NPO的原文前缀能够恢复，跨患者/跨列表项等负例被阻止。这个检查没有覆盖所有临床字段连接情况。
- 原C48候选全部保留，N526晚期HR和N585目标日记录获得真实重排机会；不保证最终入选。
- selector在3组预登记锚点（Ortho会诊、MRI身份、Definity阴性结果）均增加了baseline未选中的真实片段，ID和预算通过检查。

**没有分支在第一阶段被淘汰。** 这是如实执行门槛的结果，不是放宽标准；四者随后进入同一压力集，未改变方法规则。局部单位检查不能保证语法分界、条件归属或证据选择在其他病例仍合理。

## 4. 机制确实发生了什么，为什么还没形成净收益

35个按事前规则安排的案例/37对比较已阅读75个不同完整Judge输出，核对实际增删块、关键引用和原文位置；另跟踪事前N264/N395/N642探针的5个完整输出。不是逐条深读所有231例或所有selector解释，不能用这些选例估计总体机制占比。完整reference保存供复查，阅读复用保留原始空白布局。[当前35例诊断](review_final_002/coverage.json)和[探针跟踪](probe_followthrough.md)将观察、解释、反证和不确定性分开。

**主谓复述提高了表面遵守，仍会改变语义要求。** 合同适用167/231条，其中141条在claim_summary逐字复述原句；这不是语义保真率。N264在压力集确实由S改为NS并保留patient主体；但N100把“patient's condition”要求成整个病情所有方面，拒绝已有的病毒性胃肠炎/感染因果材料。N087已经承认入院N/V，仍要求呕吐是主要入院原因。N252对“两个主题都在但因果关系未涉及”的区分有局部帮助，却不足以抵消整体损失。合同平均输出约363 tokens，baseline约313；上限相同不等于精确等计算量，也不能说这种负结果证明所有claim-contract设计无效。

**字面恢复是真实的，条件归属和目标相关性却未充分保证。** 压力集46条reference变化；52个原入选片段的前缀触发机会中48个随视图保留，另4个被预算换段丢掉，总计丢24个原入选ID、新增21个。N086确实补回No，却被Judge用主要主诉/持续性要求拒绝入院伴随恶心；N642补回if aspiration条件后，Judge又不接受8月9日“24 Hour Events”的回顾范围。N073只补了与糖尿病类型无关的No nausea，随后医生DM2/护理Type I的取舍改变，不能算修好了糖尿病证据。

更关键的是，N580/N585的条件触发会抓到上一字段“Haldol/zyprexa for agitation **if required**”，跨过CVS/Pulmonary再补到当前片段；虽全是同note原文，也不能当作目标条件已被正确关联。N585因此带入晚期“improved CXR”，仍未找到目标日。**本版text_guard也不能直接作为通用工程修复器采用**；保留No等原文字义的质量要求依然成立，不能为了分数保留错误极性。[原文回查](mechanism_analysis_001/prefix_scope_backchecks.json)

**扩候选解除了一层限制，关键证据仍可能过不了后面的选择。** wide在180/231条改变reference，最终多选455次来自原C48外的候选，但这些不是医学召回率。N526的9月1日HR从不具备资格变为新重排第33/34，仍因字符预算未选；N585的8月20日护理段新重排第38，同样被预算舍弃。另一方面，N419的strengthening句原已在baseline，改对不能全算新召回；N627新增具体Valium给药细节，原标签本来就对。[可追溯排名/舍弃](mechanism_analysis_001/raw_traces.json)

**LLM可以选回互补段，也可以选错证据类型。** selector全231份ID选择有效、无格式退回，228条reference变化；最终平均正文加头约6304字符，baseline7895，都是同8000上限。它丢1538次原入选片段、增加916次其他原候选；145个“命题—note”组合超过原2段限制。N395选回Ortho会诊并改S，N182补入社会工作沟通/出院解释材料并改S，N530补入真实LR bolus及500cc×2却仍因throughout被拒。相反，N147丢掉5L/1L实际补液动作，留下总量表；N501只挑followup/CT标题，丢掉腹CT实际扫描和结果。ID合法、字数受控不等于集合充分。

**必须保留执行者的修正记录。** 逐ID回查撤回了初稿三处说法：N305的ASA、N425的8月5日拔管、N644的吞咽试验本来就同时在两个输入中。它们不是被删除/新补的例子，而是关键材料仍在、可见输出却使用或解释不同。阅读界面只展开“变化或被引用”的块，未展开不能当未输入；现在以[16项成员核查](membership_backcheck_001/checks.json)和review_final_002为准。87处逐字引用验证只能证明引文存在，不能独自证明增删或因果。

## 5. 当前判断与下一步

1. **停止这四个具体方案的扩大。** 没有合格单组件，所以没有组合，也没有“互补组合已经成立”的结果。不能把wide/selector的局部互补潜力当成绕过门槛的理由。
2. **未进入新患者确认，因此没有新的论文方法候选。** 原开发顺序剩余16名继续保留，40名reserved test未用。协议中的下一8人/含selector时前4人只是预定条件方案，没有做新患者检索或Judge，也没有拿压力集当自然分布确认。
3. **继续保留C48作为已有实用对照，不替换成任一013臂。** 它有已确认的缺陷，不是临床部署认可；但当前没有证据说明这些改动整体更好。基本字义保真与性能提升是两件事，本轮不能以“修复后分数下降”否定原文应保真的原则。
4. **不立即再开一个更宽的prompt、planner、融合或packaging迭代。** 当前更值得做的是整理001–013已经建立的对照结果、数据/标签适用边界和失败证据，重新论证论文要回答的问题及可验证结论。若后续仍要求提出优化方法，应另有新的明确依据和受控方案，而不是在本轮四条路线继续试参数。

本轮支持的是：这四种可实施的单组件干预在已使用开发压力集上没有值得前瞻确认的净信号；输入损失、支持关系解释和原标签边界并存。**不支持**宣称找到了唯一瓶颈、所有证据保真/选择理论都无效，或Codex已经给出新的医学正确率。无医生evidence gold、仅6名既用患者、压力集选择、不同真实输入下的生成变化、服务模型只有别名等限制均保留。
