# 108公平GPU比较：配对分析与小批输入核对

**当前hier_shared配方的固定预测综合退化，应按原规则停止本轮扩大。** 它增加正确S，同时更明显地增加错误支持，并降低NS/NA识别。自然ΔMCC及两面板false-S率差的患者bootstrap区间均在不利方向；压力ΔMCC区间跨0，不能声称所有种子或重训都稳定退化。

本报告只分析本次4090、同资料/原始预训练顶部层的flat_ce与hier_shared各500条首次预测，不以旧092 OOF或CPU廉价头冒充公平对照。两臂均有1792次成功更新、3次FP16 overflow跳步，顶部可训练参数12,596,224；内部验证选择shared第5轮、flat第4轮，未用500条选epoch。实际输入仍为原C48完整窗口，GT不变。费用、关机和最终归档由主报告另列。

## 对研究决定的含义

公平GPU对照的自然/压力均没有预写点收益信号，并违反多条风险/类别保护线。CPU头对照中的局部点信号没有转化为顶部单层适配后的公平增量。当前配方综合退化足以支持停止本轮，不再评价其余1317、第二seed或额外端到端样例；这不等于证明所有层级模型或所有种子无效。

完整点指标P/R/F1、混淆矩阵、配对区间、转移、患者与分组数据见[gpu_analysis.json](gpu_analysis.json)；准入的逐项点比较见[fair_gpu_comparison.json](fair_gpu_comparison.json)。本分析未调用GPU、模型或收费API，未提交推送；不替代主执行者的最终费用、关机与保存交付。
