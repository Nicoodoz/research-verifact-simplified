## 1. 配置是什么意思

| 名称 | 实际设置 |
|---|---|
| 作者原VeriFact | 官方发布的R1-70B预测，100 sentence facts、rerank、absolute_time、目标住院、去重；按本轮相同ID重评 |
| C48 | 我们的冻结BM25＋BGE候选/重排与final reference管线；不是Judge一定看到48段 |
| N-V / T-V | 非thinking / thinking-high；输出判断、reason和checks，不额外输出三类分数 |
| N-S / T-S | 非thinking / thinking-high；同时要求输出三类label_scores；raw指该次LLM原始判断 |
| U0 | 直接取三类分数最高者；可能与raw verdict不同，不能混为一项 |
| U2 | 对Supported的log分数加固定λ=2后判定；单独写U2时指N-S＋U2 |
| G | 冻结的Supported校准偏置；**不是Gate** |
| prior-only | 只按冻结的来源类别比例/校准样本比例修正分数 |
| PriorG | G＋上述类别比例修正；当前主配置为C48＋T-S＋PriorG |
| Gate A | 对N-S的U0→U2支持翻转，用已有Qwen分数与小模型筛选；本轮每例使用排除其患者的旧模型 |
| StdM / StdV | 标准多类偏置 / 各类分数缩放加偏置；复用历史患者外参数，应用到相同N-S分数 |

除作者发布系统外，DeepSeek均为`deepseek-v4-flash-0731`。Thinking固定high、max_tokens=8192；非thinking为2048。故thinking比较同时包含推理模式及其输出预算，不声称只改变了内部思考能力。评分接口普通/评分两臂仍共用核验检查结构。

## 3. 哪个组件真正起作用

| 组件变化（同384条） | 净正确变化 | 错误支持变化 | 主要含义 |
|---|---:|---:|---|
| N-S raw → T-S raw | +5 | −6 | thinking有风险/类别方向的改善；PA/MCC区间跨0 |
| N-S＋U2 → T-S＋U2 | −3 | −14 | 更少错误支持，但不是准确率升级 |
| N-V → N-S raw | 0 | 0 | 要求额外打分本身未提高净正确数 |
| T-V → T-S raw | +1 | 0 | 评分接口本身增量很小；其价值在于后续可利用分数 |
| N-S raw → U2 | +26 | +11 | 固定支持偏置提高一致率，同时增加错误支持 |
| U2 → U2＋Gate A | −3 | −6 | 风险折中，不是无损纠错 |
| T-S raw → T-S＋PriorG | **+32** | +4 | 当前组合的重要增量：34救回、2伤害 |
| T-S＋U2 → T-S＋PriorG | **+14** | +1 | 15救回、1伤害；PA/MCC区间均为正 |
| T-S＋G → T-S＋PriorG | +32 | +4 | 增量来自加入先验修正 |
| T-S＋仅先验修正 → T-S＋PriorG | **0** | **0** | 384条逐例标签完全相同，G没有额外分类贡献 |

T-S＋PriorG相对T-S raw的ΔPA为+8.33个百分点[+5.73,+11.20]、ΔMCC为+0.0867[+0.0404,+0.1301]。相对T-S＋U2的ΔPA为+3.65个百分点[+1.82,+5.73]、ΔMCC为+0.0457[+0.0150,+0.0754]。

**重要的简化结论：在本批数据上，PriorG中的小G偏置没有改变任何T-S最高分标签；去掉G后的prior-only又与完整PriorG逐条相同。不能把G和prior包装成两个分别有效的创新。**这只定位本轮分类作用，不保证所有未来病例均可删除G；当前参数不自动改动。

这里的“先验修正有效”是当前分布上的经验判定边界结果，不等于模型自报分数已成为可靠概率，也没有解决054–064的新环境自动适应问题。

N-S PriorG→T-S PriorG也有净+16、false-S −8，但两者使用各自051训练得到的G参数，因此这条比较包含推理模式与模式专属校准的共同变化，不应全部归功于thinking。判断thinking的独立作用，应优先看raw或同一U2的对照。

## 7. 现有成果应如何收束

1. **保留当前T-S＋PriorG作为主要研究配置。** 相对原作者MCC和错误支持有开发证据，PA改善仍有限；相对U2/Gate的配对结果更清楚。不能再泛称“所有配置都远超作者”。
2. **论文有效组件主线是推理模式与类别修正的配合。** raw上的thinking收益主要体现风险/类别结构；先验修正恢复一批真S。G在本轮无独立标签增量，不硬凑多个贡献点。
3. **C48定位为较短输入的实用管线。** 不把尚未证实的精度优势写成前处理方法贡献；final pack开发继续暂停。
4. **Gate、StdM/V保留为必要强对照。** 它们展示准确率、MCC与错误支持之间的真实交换，不能只报对我们有利的基线。
5. **F4不升级。** 新80条未兑现整体改善；077的低风险潜力是未解决的次级问题，不应继续拖住论文主线。

论文可以用本轮的配置主表、推理×评分接口消融、G/prior拆解和reference桥接构成清楚的实验结构。更大规模的034/036仍按各自证据等级引用，不能与078混成一个分母或声称当前PriorG已在reserved完成最终确认。
