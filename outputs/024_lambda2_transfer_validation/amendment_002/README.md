# 024 执行期统一解析与有效配对评价规则

2026-09-19，用户在首次性能评价前明确授权。此前原协议、amendment_001及两次暂停均保留历史记录，本修订优先适用于024全部既有和后续输出。

核心为B的唯一合法verdict；S另须唯一合法label_scores（三个原标签、整数0..100、和100）。相同核心重复值折叠；冲突或缺失核心invalid_core_fields。reason/checks非核心：重复、冲突、缺失或结构错误记录诊断，可为valid_with_format_anomaly；不人工合并，不替换原回执。无法形成唯一解释时派生解释字段置null，原文仍在output_text/原回执。普通B本就不请求label_scores，不凭空要求其有评分。截断如仍完整可确定核心，则记录异常继续；未完成的核心字段或缺核心仍invalid。不会用正则猜分数/标签。

HTTP200一律终态，不论有效/无效均不重跑。孤立真正invalid亦继续剩余请求。通信无回答失败按原规则最多3次尝试，旧预留保留。三种状态valid、valid_with_format_anomaly、invalid_core_fields。全部请求完成或达原失败重试次数后评价，不为补分母新增HTTP200调用。

系统性停发规则在续跑前固定：任何回传模型明确错误或401/403/404/400接口错误；滚动最近100个HTTP200中核心invalid至少10条且比例≥10%；连续10次无回答传输失败；或实际+未知+在途预留/剩余费用预测触及80元。少量解释/核心异常不触发这些条件。停止时收齐在途。模型、body、C48、API-BGE、λ和队列不变。

评价采用002实现：每一比较取其所需输出有效交集，显式保存各比较完整ID清单、排除ID/原因、分母及指纹。U2−U0仅需S有效；U2−B需同模型B和S；不同模型直接比较使用相应输出共同有效交集。各模型主描述表采用该模型B/S共同有效集，同时提供S-only等比较各自精确指标，不把不同分母绝对数直接相减。all/human/LLM与患者、类别分析同样使用明确的有效配对集合。保留原总体方向/强证据判据，1000次患者cluster bootstrap。
